# 懂片帝

把 `懂片帝.js` 导入 OmniBox 的 JavaScript 爬虫源即可使用。默认站点为 `https://dongpian24.com/`，下载注解已包含 GitHub 加速地址。当前版本 `1.0.1`，修复官方线路被默认隐藏的问题。

支持首页推荐、电影/电视剧/短剧/动漫/综艺/纪录片/体育分类、分页搜索、分季入口、完整分集分页、多条媒体线路、封面、可选刮削和弹幕。不接入成人专区，并按站点的成人标志和影片标题/分类过滤相关内容；错误标注无法完全识别。

## 会话与请求

站点 API 要求请求签名和游客 Cookie。脚本从公开前端文件读取当前签名配置，按前端协议发请求，不执行下载的 JavaScript；没有在脚本里固定会变化的资源文件名。

首次打开首页、分类、搜索或详情时自动创建正常游客会话，后续沿用相同游客身份。Cookie 不出现在日志、播放 ID 或公开 SDK 缓存中，只在进程内和服务端临时目录 `omnibox-dongpian` 中保存；目录权限为 0700、会话文件为 0600，按站点和 `context.sourceId` 隔离。宿主临时目录不可写时，可改用 `DONGPIAN_COOKIE`。

预热不创建/刷新游客、不写缓存或会话、不刮削。播放只读取已有会话，不创建游客；若服务重启清空临时目录，先重新打开影片详情恢复会话。自己配置的 Cookie 过期时需更新，脚本不会改用新游客代替登录账号。

## 播放线路

默认展示站点返回的直链和官方解析线路，包括游客可用的官方 4K。每次播放重新取所选分集的地址，不长期缓存最终媒体地址。线路以第一集可用线路为目录，个别后续集数缺少某条线路时会返回明确错误，可切换其他线路。

解析票据是站点获取媒体地址的协议，不能据此判断必须登录或付费。2026-11-11 使用未登录游客会话实测，“今天是太阳雨”的“专享4K-Y”成功返回 m3u8，媒体清单 HTTP 200，响应没有 `quota_delta` 字段。该结果仅证明本次游客请求可用，不代表所有影片或线路都永久无限制。

默认无需配置解析开关。仅在实际选择线路播放时提交票据，预热跳过；若想只保留直链，可设 `DONGPIAN_TICKET_LINES=0`。站点对某次请求若明确返回权限或额度错误，脚本会照常报告，不根据线路名称预先隐藏。

页面地址先尝试 SDK 嗅探，失败回退 `parse: 1`，需要客户端支持。m3u8 直链和已解析得到的 m3u8 不依赖网页嗅探。媒体请求只使用上游提供的媒体请求头，不转发懂片帝会话 Cookie。

## 可选环境变量

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `DONGPIAN_HOST` | `https://dongpian24.com` | 站点根地址，域名变更时覆盖 |
| `DONGPIAN_COOKIE` | 自动游客会话 | 使用自己的站点 Cookie，或在临时目录不可写时配置 |
| `DONGPIAN_TICKET_LINES` | `1` | 默认显示官方解析线路；显式设为 `0` 时隐藏 |
| `ENABLE_SCRAPE` | 开启 | 设为 `0` 关闭详情刮削 |

`ENABLE_SCRAPE` 沿用现有变量。地址、Cookie 和解析开关属于本站专用配置，使用 `DONGPIAN_*`，防止与其他源的会话和解析配置混用。

公共签名配置缓存 1 小时，首页/详情/分集 2 分钟，分类/搜索 1 分钟；缓存 key 使用哈希并限制单条大小。配置自己的 Cookie 时关闭内容持久缓存。播放解析不写缓存。

## 验证

2026-11-11 已进行语法检查、关键路径回归和真实 HTTP 验证。首版首页 30 条，电影分类 20 条；搜索“兰香如故”返回 3 条，详情 47 集、25 条直链线路；抽样红牛线路的 HLS 清单 HTTP 206，封面 HTTP 200；新脚本实例可复用私有会话继续获取播放地址。1.0.1 增补未登录游客的官方 4K 解析与清单请求验证。真实 HTTP 验证使用本地 SDK 替身，没有替代站点响应。宿主内的刮削、弹幕和完整视频解码尚未实测。
