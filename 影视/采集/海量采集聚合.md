# 海量采集聚合

将 `海量采集聚合.js` 作为 JavaScript 爬虫源导入 OmniBox，无需额外配置。

## 收录范围

用户提供的采集配置共 285 项，其中 284 项声明为 JSON/XML HTTP 接口。排除 43 项成人、标注含成人内容的源及其同域别名，另排除说明、TVBox 专用项及含凭据的接口；规范化并合并 76 项重复配置后，保留 162 个候选地址。

2026-11-11 首轮有 48 个接口返回标准数据，复测只有 31 个成功。默认启用这 31 个，其余 131 个保留在脚本中但关闭。探测失败可能是限流、网络、证书或地址变动，不能据此认定永久失效。

另一个 Python 配置里的 307 项均为 TVBox `type=3` 爬虫地址或类名，依赖 TVBox 的 Python/JAR 运行接口。它们不等于采集 API，本脚本没有下载执行或冒充已经接入。两个指向“采集聚合/采集合集”的公开 Python 原文件在检查时均返回 404。其他 Python 站点需要拿到有效源码后逐站适配。

## 使用方式

- 首页按来源分分类，每个来源可用“类型”筛选电影、剧集等；首屏推荐只查询一个可用来源，失败最多尝试前三个。
- 搜索并发查询默认来源，保留不同来源的独立条目，在备注里标明来源。同一来源同一影片 ID 去重；同一播放线路相同地址也去重。
- 搜索结果标题需要包含关键词（忽略空格和标点），防止忽略 `wd` 的接口混入无关首页数据。
- 搜索分页跟随各源分页；若某源混入无关结果，只保留匹配项并保守提示下一页，不采用它可能失真的总页数。过滤后的数量不一定等于上游声明的总数。
- 搜索每个接口最多等 2.5 秒，总预算默认 8 秒，超时保留已完成结果。失败和超时来源会在日志中列出，因此每次搜索不保证所有来源均响应。
- 列表、搜索缓存 60 秒，详情缓存 5 分钟；预热不写缓存、不触发刮削。播放时复用详情缓存，媒体地址和最终播放结果不另设长期缓存。
- JSON 和 XML 均能转换为 OmniBox 的五方法格式。直链线路优先；普通播放页尝试 SDK 嗅探，失败返回 `parse: 1`，需要客户端支持（目前主要是 ok影视）。没有安装完整嗅探运行环境的服务可能无法播放这类页面。
- 成人源通过名称和域名筛除，普通影视源内的伦理、三级、写真等分类和相关标题继续过滤，详情和播放也复核。过滤依赖上游分类/标题标注，无法保证识别所有错误标注内容。
- 刮削在详情里统一调用一次，弹幕在播放时匹配；增强能力不可用时保留原始数据和播放地址。宿主实际 UI、完整视频解码和全部接口均未逐一验证。

## 可选环境变量

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| `SITE_API` | 使用内置清单 | 覆盖为单个 API 地址或 JSON 数组 `[{"name":"来源","api":"https://example.com/api.php/provide/vod"}]`；仍执行成人源过滤 |
| `COLLECT_SOURCE_IDS` | 全部默认来源 | 分号/逗号分隔的来源名称或内置 ID，缩小查询范围 |
| `COLLECT_INCLUDE_UNVERIFIED` | `0` | 设为 `1` 开启全部 162 个候选地址，会增加请求量及失败率 |
| `COLLECT_CONCURRENCY` | `16` | 搜索并发数，1–24 |
| `COLLECT_TIMEOUT_MS` | `5000` | 单接口请求超时毫秒数，搜索另设 2500ms 上限 |
| `SEARCH_TIMEOUT_BUDGET_MS` | `8000` | 整体搜索预算毫秒数 |
| `ENABLE_SCRAPE` | 开启 | 设为 `0` 关闭详情刮削 |

来源清单、并发和验证开关没有现有通用变量可复用，因此使用 `COLLECT_*`，避免影响网盘脚本。`SITE_API`、搜索预算和刮削开关沿用现有名称。

首发版本 `1.0.0`。单元测试覆盖 JSON/XML、多源 ID 隔离、成人过滤、播放、缓存、预热及搜索超时；实测记录保存在本地 `reports/采集聚合实测.json`，接口审核记录在 `reports/采集接口审核.json`。
